# PETSCII-98
A tiny what-if: the desktop Commodore might have shipped in 1998. C64-style boot, a late-90s drag-and-drop desktop, a working Commodore-style BASIC and a Game Maker for writing your own games, all in one ~90 KB Windows .exe. Add the VICE emulator to play real C64 games too.

Description 

Commodore 98 Workbench

What would Commodore have made in the late 90s if it had survived? Commodore 98 is a small Windows app that boots like a C64 and loads into a late-90s desktop. There’s no install and no runtime: just unzip it and run Commodore98.exe.

A real desktop: drag icons anywhere, create notes and folders, rename things, and use a Trash you can restore from or empty. The window resizes and maximizes, so it fits any monitor.
BASIC 7.0: a working Commodore-style BASIC with a toolbar for Run, Stop, Clear, Reset and Edit.
Game Maker: write your own BASIC games with keyboard controls, colours, timing and arrays. Press Example to load DODGE, a complete game to play and learn from.
Your program library: put programs in the floppies and cassettes folders. Type LOAD"$",8 to see a numbered list, then RUN 1 to start one.
Make it yours: screen scale, small or large icons, five colour themes and more in Settings.

 Want to play real C64 games?

Commodore 98 runs BASIC games by itself. Real C64 games (.d64, .prg, .t64, .tap, .crt) need the free VICE emulator, which Commodore 98 launches for you:

Download VICE for Windows (64-bit) from vice-emu.sourceforge.io.
Unzip it into the emulator folder next to Commodore98.exe. You don’t need to rearrange anything; Commodore 98 finds VICE inside the folder it unzips to.
Put your games in the floppies or cassettes folder.
In BASIC, type LOAD"$",8 and then RUN with the game’s number. The game boots straight into VICE.
